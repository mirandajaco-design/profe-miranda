# Cortometraje V2026 — Presentaciones por sesión

Material de clase para dos espacios de formación académica (EFA) del programa de Cine y Televisión, coordinados sobre el mismo proyecto de cortometraje del semestre:

- **Dirección de Actores** (LMR3437 · 7030602417)
- **Taller de Realización Argumental** (LMR3437 · 7030402415)

Cada curso tiene 16 sesiones de clase, una presentación por sesión, generadas a partir del syllabus oficial V2026.

## Ver las presentaciones

Abre [`index.html`](./index.html) — es un visor navegable con las 16 sesiones de cada curso: menú por unidad/etapa, navegación por teclado (← →) y selector para cambiar entre los dos cursos.

Si este repositorio tiene GitHub Pages activado, la versión publicada vive en la URL del sitio (ver "About" en la barra lateral del repo).

## Archivos descargables (.pptx)

- [`pptx/direccion-actores/`](./pptx/direccion-actores) — 16 archivos, uno por sesión.
- [`pptx/taller-argumental/`](./pptx/taller-argumental) — 16 archivos, uno por sesión.

Cada presentación trae 13 diapositivas: título, agenda, idea central, exposición teórica, referentes bibliográficos, técnica/operativa, transición al bloque práctico, mecánica del ejercicio, checklist de calidad, conexión con el cortometraje conjunto, entregable, próxima sesión y cierre.

## Estructura

```
index.html                          # visor web de ambos cursos
pptx/direccion-actores/*.pptx       # 16 sesiones — paleta vino/dorado
pptx/taller-argumental/*.pptx       # 16 sesiones — paleta acero/ámbar
```
